WeatherPack

A full-stack smart travel weather planner. Type in a destination and it pulls the live forecast through a backend API then turns that into a packing list based on the conditions and what you're actually doing there. Sightseeing. A meeting. Or something outdoors.

View Live Site View Code

The problem

Travellers usually check the weather and pack separately, then still get it wrong. WeatherPack answers one question before a trip. What does the sky look like where you're going, and what should you bring for it.

What it does

  • Pulls the live forecast for any destination through a FastAPI backend
  • Lets you set the trip type: sightseeing, business, or outdoor and hiking
  • Generates a packing list based on the forecast and trip type

Tech stack

HTML CSS JavaScript FastAPI OpenWeatherMap API

Result

Deployed and live. Built to stay fast and easy to read rather than to lean on a heavy framework.
